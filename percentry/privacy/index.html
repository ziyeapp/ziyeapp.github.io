隐私政策

更新日期：2026 年 6 月 14 日

Percentry 不运营后台服务器，不包含统计 SDK、云数据库或远程日志。设置与使用历史保存在你的 Mac 上。

1. 适用范围

本政策说明 Percentry macOS App 如何读取、使用和存储额度信息。Percentry 无需注册账号，也不会建立 ZIYE 用户档案。

2. 本机保存的数据

Percentry 会在你的 Mac 本地保存运行所需的信息，包括：

  • Codex 与 Claude 的额度快照和重置时间
  • 用于图表与热力图的估算使用历史
  • 外观、后台刷新、通知时段和小组件设置

这些数据不会上传到 ZIYE 服务器。Percentry 不保存你的提示词、回复正文或钥匙串凭证内容。

3. Codex 数据来源

Percentry 调用本机安装的 codex app-server 读取额度元数据。该过程发生在你的 Mac 上，不经过 ZIYE 服务器。Codex CLI 和 OpenAI 服务本身受其各自的条款与隐私政策约束。

4. Claude 数据来源

Percentry 读取 Claude Code 已保存在 macOS 钥匙串中的登录凭证，并从你的 Mac 直接请求 Anthropic 官方额度端点。凭证只用于向 Anthropic 验证你自己的账号，不会发送给 ZIYE 或其他第三方。Anthropic 对该请求的处理受其隐私政策约束。

5. 系统权限

  • 钥匙串访问：读取 Claude Code 已有的登录凭证。macOS 首次会要求你授权。
  • 通知权限：在你启用重置通知后发送本地桌面通知。

6. 数据共享与分析

Percentry 不出售个人数据，不投放广告，也不集成第三方统计或追踪 SDK。除 App 为获取额度而直接联系 OpenAI/Anthropic 的官方组件或端点外，不会向其他服务发送额度历史。

7. 你的控制权

你可以在 Settings 中清除使用历史、关闭后台刷新或通知。你也可以在 macOS 系统设置中撤销通知权限，并通过钥匙串访问工具管理 Claude Code 凭证。

8. 政策更新

如果数据处理方式发生实质变化，本页面会更新说明与日期。新版本发布前会优先保持本政策所述的本地优先原则。

9. 联系方式

隐私问题可联系： ziyeapp[at]gmail.com
