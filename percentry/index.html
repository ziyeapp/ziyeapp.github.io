01 / AT A GLANCE

额度信息，放在最顺手的位置

菜单栏负责随时查看，桌面小组件负责一直可见。两种方式都展示剩余百分比和重置时间。

01 / MENU BAR

最紧张的额度，始终在菜单栏

数字显示所有 5 小时窗口里剩余最低的百分比，点开即可分别查看 Codex 与 Claude。

5HWEEKRESET
02 / WIDGETS

小、中、大，放进你的桌面

三种尺寸都展示 5 小时与每周额度，每 5 分钟自动更新。

SMALLMEDIUMLARGE
03 / DASHBOARD

不只看余量，也看使用历史

额度卡片、每日或每月使用柱状图，以及按天显示的 Token 热力图，全部汇总在一个紧凑的 Dashboard 中。

  • 01Codex 与 Claude 额度卡片
  • 02日 / 月用量切换
  • 03Token 使用热力图
04 / NOTIFICATIONS

在合适的时间，提醒额度已经重置

设置多个工作时段、单独开关或全天模式。额度在启用时段内重置时，Percentry 会发送桌面通知。

  • 01支持多个通知时段
  • 02每个时段可独立启用
  • 03内置测试通知
05 / PRIVACY FIRST

没有服务器，数据在本机

Percentry 不包含统计 SDK、云数据库或远程日志。Codex 数据由本机 codex app-server 提供；Claude 使用 Claude Code 已保存在钥匙串中的凭证，直接查询 Anthropic 官方额度端点。不会向第三方发送提示词、回复或令牌内容。

系统要求

  • macOS 14.0 Sonoma 或更高版本
  • 支持 Apple Silicon 与 Intel Mac
  • Codex：本机安装 Codex CLI 并已登录
  • Claude：安装 Claude Code，并在终端完成订阅账号登录

安装方式

  1. 打开 Percentry.dmg，将 App 拖入“应用程序”
  2. 首次读取 Claude 时，在钥匙串授权中选择“始终允许”
  3. 在桌面“编辑小组件”中搜索 Percentry
