Percentry · Support

常见问题

关于安装、额度来源、菜单栏、小组件与隐私。

Claude 显示 Not available？

Percentry 读取 Claude Code 写入 macOS 钥匙串的订阅凭证。请在终端运行 claude，输入 /login，并选择带订阅的账号。登录后重启 Percentry，首次授权时选择“始终允许”。只在 VS Code 扩展中登录可能无法写入所需凭证。

菜单栏数字为什么一直是某个低值？

该数字取所有 5 小时窗口中剩余最低的百分比，用来代表当前最紧张的额度。点开菜单栏面板可分别查看 Codex 与 Claude。

小组件没有数据怎么办？

确认 Percentry 已从“应用程序”文件夹启动过一次，并等待首次刷新。若开发机曾用 Xcode 运行旧版本，可能存在小组件注册冲突；普通 DMG 安装用户通常不会遇到。

数据多久更新一次？

菜单栏与桌面小组件每 5 分钟自动刷新。你也可以在 Dashboard 中点击 Refresh 手动刷新。

Percentry 从哪里获得额度数据？

Codex 数据来自本机 codex app-server。Claude 数据使用 Claude Code 已存在于钥匙串中的凭证，从你的 Mac 直接查询 Anthropic 官方额度端点。两者都不经过 ZIYE 后台服务器。

Percentry 会读取提示词或回复吗？

不会。Percentry 只处理额度百分比、重置时间以及用于本地历史图表的数值字段，不保存提示词、回复内容或令牌正文。

只安装 Codex 或 Claude 其中一个可以吗？

可以。已配置的服务会正常显示，另一个显示 Not available。

重置通知如何工作？

你可以添加多个通知时段、单独开关或选择全天。额度在启用时段内重置时，Percentry 会发送本地桌面通知；菜单栏 App 需要保持运行。

支持哪些 Mac？

需要 macOS 14.0 Sonoma 或更高版本。Percentry 是 Universal App，同时支持 Apple Silicon 与 Intel Mac。

为什么首次读取 Claude 时会弹出钥匙串授权？

Percentry 需要读取 Claude Code 已保存的登录凭证来查询你自己的额度。macOS 会在首次访问时要求授权。选择“始终允许”后，后续刷新可静默进行。

App 如何安装？会通过 App Store 发布吗？

Percentry 通过官网提供经过 Developer ID 签名和 Apple 公证的 DMG，不计划上架 App Store。打开 DMG 后，将 Percentry 拖入“应用程序”即可。
